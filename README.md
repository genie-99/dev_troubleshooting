# dev_troubleshooting

이 저장소는 공부하거나 작업하다가 겪은 문제를 "이름별로 정리해서" 다시 찾아볼 수 있도록 만든 troubleshooting 모음집입니다.

## 목적
- 발생한 문제를 바로 검색할 수 있도록 정리합니다.
- 같은 유형의 오류를 다시 마주쳤을 때 빠르게 참고할 수 있습니다.
- 개인 학습 기록과 경험 공유의 기반이 됩니다.

## 정리 방식
각 문제는 다음 기준으로 정리하는 것을 권장합니다.

1. 문제 이름
   - 예: "git push rejected"
2. 발생 상황
   - 언제, 어떤 환경에서 발생했는지
3. 원인
   - 왜 문제가 생겼는지
4. 해결 방법
   - 실제로 적용한 해결 과정
5. 참고 링크 / 메모
   - 관련 명령어, 문서, 참고 자료

## 폴더 구성 제안
현재 저장소는 주제별로 나누어 관리하기 좋습니다.

- git/
  - Git 관련 오류 및 해결 방법
- java/
  - Java / JVM / 빌드 관련 문제
- web/
  - 프론트엔드, 브라우저, HTTP, 서버 관련 문제

각 폴더 안에는 문제 이름으로 파일을 만들면 관리하기 쉽습니다.
예시:
- git/git-push-rejected.md
- java/jdk-version-mismatch.md
- web/cors-error.md

## 추천 문서 템플릿
각 문서는 아래 형식으로 쓰면 일관성이 좋습니다.

```md
# 문제 이름

## 발생 상황
- 

## 원인
- 

## 해결 방법
- 

## 참고
- 
```

## 운영 원칙
- 문제는 한 번에 하나씩 명확하게 정리합니다.
- 해결 과정을 실제로 확인한 내용만 기록합니다.
- 나중에 다시 찾기 쉬운 제목을 사용합니다.

이 방식은 혼자 공부할 때도 좋고, 나중에 팀원과 공유할 때도 매우 유용합니다.
