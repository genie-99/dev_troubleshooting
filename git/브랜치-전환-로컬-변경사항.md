# 브랜치 전환 시 로컬 변경사항으로 인한 오류

## 코드
```bash
git switch master
```

## 오류 코드
```text
error: Your local changes to the following files would be overwritten by checkout:
        article.txt
Please commit your changes or stash them before you switch branches.
Aborting
```

## 해결 방법
1. 현재 변경사항을 커밋합니다.
2. 필요하면 git stash로 임시 저장합니다.
3. 다시 브랜치를 전환합니다.

## 해결 완료
브랜치 전환 전에 로컬 변경사항을 정리하면 문제 없이 이동할 수 있습니다.

## 정리
- 로컬 변경사항이 있으면 Git은 브랜치를 바꾸지 않습니다.
- 커밋 또는 stash가 가장 흔한 해결 방법입니다.
- 작업 중인 파일은 확인한 뒤 브랜치 전환을 진행하는 것이 안전합니다.
