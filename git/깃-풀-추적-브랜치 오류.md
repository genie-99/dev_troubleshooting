# Git pull 시 Tracking Information 오류

## 코드
```bash
git switch sangjin
git pull
```

## 오류 코드
```text
There is no tracking information for the current branch.
Please specify which branch you want to merge with.
```

## 해결 방법
1. 현재 브랜치가 맞는지 확인하고 이동합니다.
2. 원격 저장소의 최신 정보를 가져옵니다.
3. 원격 브랜치와 연결한 뒤 push합니다.

## 해결 완료
로컬 브랜치와 원격 브랜치의 추적 관계를 설정하면 `git pull`과 `git push`를 정상적으로 사용할 수 있습니다.

## 정리
- `git pull`이 실패하는 경우는 보통 추적 브랜치가 없기 때문입니다.
- `git fetch origin`로 원격 정보를 먼저 가져오면 안전합니다.
- `git merge origin/main`로 합칩니다.
- `git push -u origin sangjin`을 한 번 실행하면 이후에는 `git pull`과 `git push`가 간단해집니다.
