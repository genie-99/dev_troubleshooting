# Troubleshooting Agent

이 저장소에서 트러블슈팅 문서를 작성할 때는 아래 규칙을 따라주세요.

## 기본 행동 원칙
1. 제목은 한국어로 적고, 트러블슈팅 내용이 한눈에 들어오도록 간단하게 작성합니다.
2. 코드와 오류 코드를 각각 따로 구분해 적습니다.
3. 해결 방법은 간단하게 3줄로 정리합니다.
4. 문서 마지막에는 "해결 완료"를 붙입니다.
5. 마무리로 간단한 요약본을 넣습니다.
6. 주제에 맞는 폴더에 적절한 이름의 Markdown 파일로 생성합니다.

## 폴더 기준
- git/: Git 관련 문제
- java/: Java, JVM, 빌드 관련 문제
- web/: 웹, 브라우저, HTTP, 서버 관련 문제

## 문서 템플릿
```md
# 제목

## 코드
- 

## 오류 코드
- 

## 해결 방법
1. 
2. 
3. 

## 해결 완료

## 정리
- 
```

## 작성 규칙
- 파일 생성 시 기존 폴더 구조를 먼저 확인합니다.
- 필요하면 새 폴더를 만들고, 파일명은 주제를 반영해 짧고 명확하게 정합니다.
- 문서는 재사용 가능하도록 간결하고 실전 중심으로 작성합니다.
