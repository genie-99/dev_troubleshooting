# 자바 컴파일 문법 오류

## 코드
```java
public class Test02 {
    public static void main(String[] args) {
        int[] iArr = iArr;
        iArr = new int[3];
    }
}
```

## 오류 코드
```text
Exception in thread "main" java.lang.Error: Unresolved compilation problems:
The left-hand side of an assignment must be a variable
Syntax error, insert ". class" to complete Expression
 iArr cannot be resolved to a variable
Syntax error, insert "VariableDeclarators" to complete LocalVariableDeclaration
Syntax error, insert ";" to complete LocalVariableDeclarationStatement
at day02.Test02.main(Test02.java:5)
```

## 해결 방법
1. 변수를 선언할 때는 이미 선언된 변수를 다시 참조하지 않도록 합니다.
2. 배열은 `new int[]{...}` 또는 `new int[3]`처럼 올바르게 초기화합니다.
3. 변수 이름과 선언 위치를 확인해 잘못된 참조가 없는지 점검합니다.

## 해결 완료
문법 오류를 수정하고 올바른 배열 초기화 방식으로 바꾸면 컴파일이 정상적으로 진행됩니다.

## 정리
- 이 오류는 주로 자바 문법 오류나 배열 초기화 방식 문제로 발생합니다.
- 변수 선언과 초기화 순서를 확인하는 것이 중요합니다.
- 에러 메시지의 핵심 문구를 기준으로 원인을 좁혀가면 해결이 빠릅니다.
